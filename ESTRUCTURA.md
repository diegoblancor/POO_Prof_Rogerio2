```

│   ├── estruturas_condicionais/(MaiorNumero, VerificarIdade, VerificarQuadrante, MenuSwitch)

└── projetos/                   ← Projetos integrados

    └── gerenciador_jogos/      (GerenciadorJogos.java)
```

## 📖 Como Usar

### Compilar e Executar um Arquivo

```bash
# Exemplo: Compilar
javac src/conceitos_basicos/entrada_saida/Saudacao.java

# Executar (do diretório do arquivo)
java Saudacao
```

### VS Code - Recomendado

1. Abra a pasta do projeto no VS Code
2. Instale a extensão "Extension Pack for Java"
3. Clique com botão direito no arquivo Java
4. Selecione "Run" ou "Debug"

## 🔧 Conceitos Cobertos

✅ **Entrada/Saída**: Scanner, System.out
✅ **Tipos de Dados**: int, double, String, char, boolean
✅ **Operadores**: Aritméticos, Comparação, Lógicos
✅ **Condicionais**: if-else, switch-case
✅ **Loops**: for, while, do-while
✅ **Arrays**: 1D e 2D
✅ **Métodos**: Estáticos, com parâmetros e retorno
✅ **Strings**: length(), charAt(), toUpperCase(), toLowerCase(), contains()
✅ **Math**: Math.abs(), Math.ceil(), Math.floor()

## 💡 Dicas de Estudo

1. **Comece pelo Nível 1** - Entenda entrada e saída
2. **Pratique cada conceito** - Não pule nenhum arquivo
3. **Teste o código** - Execute e veja o resultado
4. **Modifique os exemplos** - Experimente mudar valores
5. **Combine conceitos** - Faça suas próprias variações

## 📌 Importante

- Sempre feche o Scanner com `entrada.close()`
- Use nomes significativos para variáveis
- Teste seu código várias vezes
- Não memorize - **entenda** o código
